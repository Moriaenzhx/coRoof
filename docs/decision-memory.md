# 阶段 6：决策经验与老板偏好

本阶段承接已通过的知识库门槛，实施 Slice 04 决策记忆。目标是让后续持续 Agent 参考可靠的历史案例及本人确认的经营重点；不会从聊天自动固化人格、能力、绩效评价，也不把建议当成已发生事实。

经验候选绑定一项已确认决策和一条明确记录的实际结果，展示当时选择、结果原文、适用条件与经验解释；未记录结果时不能提炼经验。来源以租户复合外键绑定。候选可由本人编辑或通过现有 LangChain/LangGraph 生成，模型必须逐字引用实际结果；只有作者明确确认后才能检索。新结果出现时旧经验标为需复核，不继续作为当前有效经验。历史失败、不确定结果与相互冲突的结果同样保留，不按“成功”筛选。

老板偏好只属于当前企业里的本人 Owner，可记录关注重点、沟通方式、决策约束及规划目标；来源是本人明确输入，先成为候选，经本人确认后生效。模型可以整理候选，但不能创建确认凭据、扩大权限或把偏好变成业务事实。其他 Owner 也不能读取本人的私有偏好。修改已确认条目会重新进入候选状态；撤销后停止检索；删除清除条目内容与依赖的分析正文，保留不含正文的事件审计。

经验与偏好使用 `MemoryEntry` 领域记录（kind 明确区分），复用 SQLAlchemy/Alembic、已有版本/幂等事务、文本检索和 Agent 失效处理。模型候选采用现有读取图的有界单轮任务，人工确认复用 LangGraph interrupt/Command；不引入第二套 Agent、自动训练、独立向量库或不带业务授权的框架记忆存储。持久化检查点仍只存路由、目标、版本，不复制内容。

Agent 增加 `experience.reference` 和 `preference.read`，仅 Owner 可调用；具体事项任务只参考对应事项经验。经验展示来源与条件，偏好展示本人确认状态，引用必须逐字可核对，不据此捏造当前工作状态。规划与优先级问题先检查可用偏好；没有偏好或案例时明确未知。模型请求仍受统一租户预算、当前权限、源版本及取消检查约束。

Owner 从主导航“决策经验”查看案例，从“个人设置”管理本人 AI 偏好；两处均保留候选/已确认/需复核状态、来源详情、AI 整理、本人编辑确认、撤销和删除。所有命令追加 WorkEvent 并与记录同事务；经验事件关联原事项，偏好事件有明确偏好目标，不能创建虚构事项。来源结果追加、条目变更及删除同步使相关旧 Agent 结果失效；新查询继续按当前租户、Owner 身份和事项权限过滤。

验收门槛：无实际结果不产生经验；候选不进入模型检索；跨企业/普通成员/其他老板私有偏好隔离；来源复合外键；AI 伪造引文和指令注入拒绝；作者确认、幂等与 PostgreSQL 版本竞争；修改/撤销/删除及在途模型失效；后续结果使旧经验需复核；失败案例与冲突信息保留；现有 LangGraph 确认恢复；页面交互、真实开发模型合成场景、全栈回归和本地预览。真实身份与外部试点仍在后续门槛，不以开发数据替代。


## 实现接缝

迁移 `0010_memory` 新增 MemoryEntry / MemoryUse、实际结果来源复合唯一约束、偏好事件目标和 Agent 候选绑定。经验源版本随 DecisionOutcome 追加推进；查询过滤过期经验，更新源的事务同时使相关 Agent 结果失效。确认同类偏好采用组织命令串行化及数据库部分唯一索引，跨租户与跨决策结果不能关联。

API 位于 `/api/v1/memory/entries`，提供来源候选、编辑、明确确认/撤销/删除；`/memory/search` 仅返回当前有效的已确认条目。Owner 主导航“决策经验”提供真实来源选择、原文核对、候选编辑和人工确认；“个人设置”中的本人 AI 偏好不会因其他人同为 Owner 而共享。OpenAPI 生成页面 DTO。

`memory_draft` 使用 LangChain 的严格候选 Schema 和现有 LangGraph 生成/确认图，当前执行者、候选版本与实际来源在调用前后复查；网络调用不持有事务锁。确认图检查点只保存路由和目标版本，引用正文留在可失效的领域结果中。读取图新增 `experience.reference` / `preference.read`，版本为 `agent-read-v4` / `agent-proposal-v3`；重复事实引用在模型上下文中去重，默认额度保护保留。

离线验收命令：`cd backend && uv run pytest tests/test_memory.py -q`；并发验收须设置独立 PostgreSQL 测试库 `COROOF_TEST_DATABASE_URL`。真实开发验收使用 `scripts/agent_acceptance.py --memory --knowledge --actions --config-file .local/coding-plan-test.json --database-url <独立测试库> --report .local/memory-live-acceptance.json`，最多 51 次调用，不自动重试，仅使用合成资料，不读取业务环境中的 API Key。通用 MaaS、真实外部项目及生产身份验收仍单列。
